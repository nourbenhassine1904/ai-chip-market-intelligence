Turn the completed scientific study into a readable, executable and transferable
university project. No new model, tuning, Yahoo download, new holdout forecast,

initially clean. Phases 1–8 scientific outputs are preserved byte-for-byte.

The notebook requires the complete committed artifacts but neither local market
data nor fitted neural weights. Source paths are relative to the repository.
It verifies checksums before displaying a table, text or figure; renders published
PNGs; plots archived loss series; checks chronology/common targets and computes
MSE/RMSE/MAE/MAPE from the already-frozen prediction CSV, comparing to published
metrics. It does not recalculate DM, train models or rerank/select them.

## Data provenance

The original seven local CSVs were checked against Phase 1, 1.5 and 2 historical
manifests: raw NVDA/AMD/SOXX, canonical, features, TRAIN, TEST. All seven hashes
match. Hashing TEST bytes for integrity is not reading its observations for a
new evaluation. FAST never accesses data/ at all.

A clean clone contains only data placeholders. Obtain the original snapshots
from the team or regenerate in an independent clone. No archived original dataset

divergence; comparison must use the reference manifests rather than the newly
written acquisition manifest. Divergent snapshots must not replace official data

## Execution modes and RStudio

**FAST** runs the notebook only: published evidence plus arithmetic verification.
The nbclient executor uses the current `.venv` Python and runtime guards against
data reads, network calls, subprocesses, model-library imports and writes inside
the scientific repository. Hashes are checked before/after; a portable checkout
may match the exact captured bytes or exact committed blob bytes. The runtime
compares its own initial/final digests so a representation change during execution
also fails. The second run uses committed LF representation without data/, .git
or ignored historical model caches. The kernel is explicitly shut down afterward.

**FULL** is a manual, isolated procedure using authentic scripts and documented
R/Python summary ordering. It was not executed in Phase 9A. Acquisition, preparation,
EDA, classical models and bounded original neural training are documented. Strict
new Phase 7 forecasting from the final checkout remains PARTIAL because the runner
refuses to overwrite archived predictions and snapshot/cache/protocol provenance
must be prepared in a separate evaluation run. `--summarize` replays derivatives
from frozen predictions; it is not reestimation. Do not remove the gate in the
reference checkout or retune from historical final scores.

RStudio uses the existing `ai-chip-market-intelligence.Rproj`, the same root
and `.cache/R-library`. Required packages: forecast, tseries, FinTS, vars, urca,
rugarch. Four classical R scripts were inspected and parsed, without executing
historical models. `r/01_data_eda.R` is explicitly documented as a placeholder.
Install packages manually and run only in the isolated reproduction clone.

verify source syntax, paths, links, references, commands, metric provenance, full
scientific manifest coverage and archived Git blob digests, runtime evidence and
tampering rejection. Test-source baseline fingerprints are retained separately;

## Reproducibility limitations

Observed environment: Python 3.12.3, TensorFlow 2.21.0 on native Windows CPU
(device query shows no GPU), R 4.5.2 and all six required R packages present.
Initial and post-install pip checks found no broken requirements. Notebook
dependencies were installed with explicit approval; initial configured-index
failures were resolved using official PyPI. No GPU, registry or policy changes.
The guides cite [Microsoft path limits](https://learn.microsoft.com/en-us/windows/win32/fileio/maximum-file-path-limitation)
and [TensorFlow Windows installation](https://www.tensorflow.org/install/pip).

Original inventory had 164 working-tree/Git-blob hash differences among 315 files
(including tests), from Windows text representation. These preexisting differences
are distinguished from modifications; historical CSV/data digests are not silently
normalized. Most dependencies remain unpinned, exact data/weights are ignored,
Yahoo can revise history, and TensorFlow bit-for-bit equivalence is not guaranteed.
The official LLM's precise model and generation metadata remain unavailable.
Team baselines are not independently verified as human-only/blinded work.
